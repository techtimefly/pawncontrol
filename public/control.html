KEEP THE CONVERSATION MOVING

Calls to action.

Personalize messages with variables such as {channel} and {wins}.

Available variables — names, scores and ratings

Names

  • {channel} — your channel / creator name, or “this channel” when blank.
  • {username} — your configured Chess.com username.

Example: Follow {channel} for more chess!

Current session

  • {wins} — total wins.
  • {losses} — total losses.
  • {draws} — total draws.
  • {streak} — current streak, such as 3W or 2L; — when there is no streak.

Example: Today: {wins} wins, {losses} losses, {draws} draws

Ratings and goals

  • {blitz_rating} — current blitz rating.
  • {rapid_rating} — current rapid rating.
  • {bullet_rating} — current bullet rating.
  • {blitz_goal} — configured blitz goal.
  • {rapid_goal} — configured rapid goal.
  • {bullet_goal} — configured bullet goal.

Ratings use a manual override when set, otherwise the latest available Chess.com rating.

Example: Blitz climb: {blitz_rating} / {blitz_goal}

What viewers see

  • Use the exact lowercase names and braces shown above, in either editor or text format.
  • Preview changes shows your literal text, including variables. The Live preview and overlay substitute available values.
  • If a known variable has no value (for example, an unavailable rating), the whole message is skipped.
  • Unknown variables stay as written. For example, {unknown} appears literally.

Structured blocks preserve IDs and enabled flags. Text is required; new messages default to enabled. Keep ID lines for existing messages, including duplicate text. Omitted metadata on existing IDs stays unchanged.

Examples and help

Simple list

  • Write one message per line. Blank lines are ignored.
  • Each line creates a new enabled message. IDs, disabled flags and multiline text cannot be preserved in this format.
  • Switching formats asks for confirmation and starts a fresh draft. Simple list starts empty; cancel to keep your draft.
Follow {channel} for more chess!
Session wins: {wins}

Structured blocks

  • Separate messages with a blank line. Text is required.
  • Enabled accepts yes or no. New messages default to enabled.
  • Keep existing ID lines to preserve identity and saved metadata. Omitted metadata on an existing ID stays unchanged.
Text: Follow {channel}: more chess!
Enabled: yes

Text: Wins: {wins}
Enabled: no

Append or replace

  • Append adds new messages. Remove ID lines or write new blocks.
  • Replace all replaces the entire saved list after confirmation. An empty draft clears the list.
  • Simple-list replacements create new IDs and enabled messages.
  • Undo is one step, on this page only, and requires no subsequent message changes.

Limits

  • 50 saved messages total.
  • 500 characters per message; 80 per ID.

Multiline text

In structured blocks, use JSON quotes for line breaks or significant outer spaces:

Text: "First line\nSecond line"

All values are plain text, never HTML.

Preview

Choose Preview changes to validate the draft before applying. It shows variables literally; the Live preview substitutes values. Open Available variables above for the full reference.
